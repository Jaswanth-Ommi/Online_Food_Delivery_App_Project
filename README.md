
# 🍔 Online Food Delivery Analytics System (SQL + AI)

## 📌 Project Overview

This project focuses on analyzing an **Online Food Delivery Business** dataset using **SQL, Excel, and Power BI** to generate meaningful business insights.

The goal is to simulate a real-world data analyst role by working on raw data, transforming it, and building an **interactive dashboard** for decision-making.

---

## 🎯 Business Objective

The project aims to help improve:

* 📈 Revenue Performance
* 👥 Customer Retention
* 🍽️ Restaurant Growth
* 📦 Product Performance
* 🚚 Operational Efficiency

---

## 🛠️ Tools & Technologies Used

* **SQL** – Data cleaning, transformation & analysis
* **Excel** – Data export & intermediate analysis
* **Power BI** – Dashboard & data visualization
* **AI Concepts** – Analytical thinking & optimization logic

---

## 🗂️ Dataset Description

The database consists of the following tables:

* Customers
* Restaurants
* Orders
* Order Items
* Delivery Agents

Key attributes include:

* Order Amount
* Discount
* Order Date
* Delivery Time
* Ratings
* Payment Method

---

## 🔄 Project Workflow

### 1️⃣ Data Cleaning & Preparation

* Handled missing values
* Removed inconsistencies
* Structured raw data for analysis

### 2️⃣ SQL Data Analysis

Performed multiple SQL queries to extract insights:

#### 📊 Exploratory Data Analysis (EDA)

* Total Revenue
* Orders per City
* Top Customers

#### 👤 Customer Segmentation

* Gold (≥ 1000 spending)
* Silver (≥ 500 spending)
* Bronze (< 500 spending)

#### 🍴 Restaurant Analysis

* Top Restaurants by Revenue
* Rating vs Revenue Analysis

#### 🚚 Delivery Analysis

* Average Delivery Time
* Late Deliveries (>45 mins)

#### 💳 Payment & Discount Analysis

* Payment Method Distribution
* Discount Impact on Revenue

---

## ⚡ Advanced SQL Implementation

* ✅ Common Table Expressions (CTEs)

* ✅ Stored Procedures (Top N Restaurants)

  * Prevent negative discounts
  * Detect delivery delays

## 📊 Dashboard & Visualization

Created an **interactive Power BI dashboard** including:

* 📌 KPI Cards (Revenue, Orders)
* 📍 Revenue by City
* 📈 Monthly Revenue Trends
* 👥 Top Customers
* 🥧 Payment Distribution
* ⏱️ Delivery Performance

---

## 💡 Key Insights

* 💰 Gold customers contribute the highest revenue
* 🍽️ Few restaurants generate majority of revenue (Pareto principle)
* 🚚 Late deliveries affect customer satisfaction
* 💸 Discounts reduce overall profit margins
